# The label editor in React, Angular and Vue

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

The web label editor embedded in a page of your own application, once in each of React, Angular and Vue. The editor is a JavaScript product, delivered as a package for each framework, and it talks only to the API server that you run. The sample opens a template, lets you change it and saves it. When the three versions exist, each will have its own subfolder in this folder.

## What you will need

- An API server that you installed and run yourself, with its address and an API key.
- The label editor add-on, and the package for the framework you use. Without a license for the add-on, the editor shows a banner and a watermark and stays fully usable.
- A web project in React, Angular or Vue. The tools and versions it needs will be listed in the README of each version.
- A current version of Edge, Chrome, Firefox or Safari.
- Nothing can be installed yet, because BarcoderX is not released.
