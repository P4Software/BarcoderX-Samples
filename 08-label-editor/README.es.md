# El editor de etiquetas en React, Angular y Vue

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

El editor web de etiquetas incorporado en una página de su propia aplicación, una vez en cada uno de React, Angular y Vue. El editor es un producto de JavaScript, que se entrega como un paquete para cada framework, y se comunica solo con el servidor de API que usted ejecuta. El ejemplo abre una plantilla, le permite cambiarla y la guarda. Cuando existan las tres versiones, cada una tendrá su propia subcarpeta dentro de esta carpeta.

## Qué necesitará

- Un servidor de API que usted instaló y ejecuta por su cuenta, con su dirección y una clave de API.
- El complemento editor de etiquetas y el paquete del framework que usted use. Sin una licencia del complemento, el editor muestra un aviso y una marca de agua y sigue siendo plenamente utilizable.
- Un proyecto web en React, Angular o Vue. Las herramientas y versiones que necesita se indicarán en el README de cada versión.
- Una versión actual de Edge, Chrome, Firefox o Safari.
- Todavía no se puede instalar nada, porque BarcoderX aún no está publicado.
