# Códigos de barras (lineales, 2D, GS1)

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

Códigos de barras de cada tipo en una misma hoja de etiquetas: códigos lineales como Code 128 y EAN-13, códigos 2D como QR Code y Data Matrix, y los códigos GS1 que se usan en logística y comercio, como GS1-128 y SSCC-18. Muestra cómo BarcoderX maneja los dígitos de control y el texto legible, y qué pasa cuando los datos no son válidos: usted recibe un mensaje claro, no un fallo del programa.

## Qué necesitará

- El SDK de .NET 10.
- Windows x64, Linux x64 o Linux arm64.
- Los paquetes del SDK de BarcoderX, cuando estén publicados. Todavía no se puede instalar nada.
- Los códigos de barras 2D pertenecen a la edición Ultimate. Con otra edición, la etiqueta se imprime igual, lleva la marca de evaluación y un mensaje indica qué falta.
- Ninguna clave de licencia para probarlo. Sin ella, el resultado lleva la marca de evaluación.
