# Barcodes (linear, 2D, GS1)

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

Barcodes of each kind on one label sheet: linear codes such as Code 128 and EAN-13, 2D codes such as QR Code and Data Matrix, and the GS1 codes used in logistics and retail, such as GS1-128 and SSCC-18. It shows how BarcoderX handles check digits and the human-readable text, and what happens when the data is not valid: you get a clear message, not a crash.

## What you will need

- The .NET 10 SDK.
- Windows x64, Linux x64 or Linux arm64.
- The BarcoderX SDK packages, once they are released. Nothing can be installed yet.
- 2D barcodes belong to the Ultimate edition. With another edition, the label still prints, it carries the evaluation mark and a message says what is missing.
- No license key to try it. Without one, the output carries the evaluation mark.
