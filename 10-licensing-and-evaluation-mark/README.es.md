# Licencias y la marca de evaluación

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

La misma etiqueta creada dos veces: una sin clave de licencia y otra con una clave que usted posee. Sin clave, BarcoderX funciona por completo, y cada etiqueta lleva la marca de evaluación, una banda negra a lo largo del borde superior con el texto BARCODERX EVALUACIÓN (BARCODERX EVALUATION en inglés). Con una clave válida, la marca desaparece. El ejemplo también muestra que una clave ausente o dañada nunca impide crear ni imprimir una etiqueta. En el peor de los casos, el resultado lleva la marca.

## Qué necesitará

- El SDK de .NET 10.
- Windows x64, Linux x64 o Linux arm64.
- Los paquetes del SDK de BarcoderX, cuando estén publicados. Todavía no se puede instalar nada.
- Solo para la segunda parte, una clave de licencia que usted posea. Trátela como un secreto: nunca la suba a un repositorio, ni la pegue en una incidencia ni la incluya en una captura de pantalla.
