# Licensing and the evaluation mark

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

The same label made twice: once without a license key, and once with a key that you hold. Without a key, BarcoderX still works fully, and every label carries the evaluation mark, a black band along the top edge with the text BARCODERX EVALUATION (BARCODERX EVALUACIÓN in Spanish). With a valid key, the mark is gone. The sample also shows that a missing or damaged key never stops a label from being made or printed. At worst, the output is marked.

## What you will need

- The .NET 10 SDK.
- Windows x64, Linux x64 or Linux arm64.
- The BarcoderX SDK packages, once they are released. Nothing can be installed yet.
- For the second part only, a license key that you hold. Treat it as a secret: never commit it to a repository, paste it into an issue or include it in a screenshot.
