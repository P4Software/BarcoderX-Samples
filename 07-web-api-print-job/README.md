# The web API: create a print job and read its status

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

How a program in any language asks the API server that you run to print a label, and then reads the status of that job until it is finished. A print job moves through states such as Queued, Printed and Failed, and the sample says in plain words which one it reached and what to do if the job failed. Whether the sample is a C# program, a set of curl commands or both is decided when it is added.

## What you will need

- An API server that you installed and run yourself. BarcoderX hosts nothing for you.
- An API key from that server.
- A printer registered on that server, and a print agent on the printer's network. See the print agent sample.
- For a C# sample, the .NET 10 SDK on Windows x64, Linux x64 or Linux arm64.
- Nothing can be installed yet, because BarcoderX is not released.
