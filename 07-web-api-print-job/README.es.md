# La API web: crear un trabajo de impresión y leer su estado

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

Cómo un programa escrito en cualquier lenguaje le pide al servidor de API que usted ejecuta que imprima una etiqueta, y cómo lee después el estado de ese trabajo hasta que termina. Un trabajo de impresión pasa por estados como Queued (en cola), Printed (impreso) y Failed (fallido), y el ejemplo dice con palabras sencillas a cuál llegó y qué hacer si el trabajo falló. Si el ejemplo será un programa en C#, un conjunto de comandos curl o ambos se decidirá cuando se agregue.

## Qué necesitará

- Un servidor de API que usted instaló y ejecuta por su cuenta. BarcoderX no aloja nada por usted.
- Una clave de API de ese servidor.
- Una impresora registrada en ese servidor y un agente de impresión en la red de la impresora. Vea el ejemplo del agente de impresión.
- Para un ejemplo en C#, el SDK de .NET 10 en Windows x64, Linux x64 o Linux arm64.
- Todavía no se puede instalar nada, porque BarcoderX aún no está publicado.
