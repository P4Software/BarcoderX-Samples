# First label in code

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

A small .NET console program that makes one label in code, renders it and says in plain words what it did. It is the shortest path from nothing to a finished label. It uses the SDK inside your own program, with no server and no network connection.

## What you will need

- The .NET 10 SDK.
- Windows x64, Linux x64 or Linux arm64.
- The BarcoderX SDK packages, once they are released. Nothing can be installed yet.
- No license key. Without one, the label carries the evaluation mark.
