# Primera etiqueta en código

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

Un programa de consola de .NET pequeño que crea una etiqueta desde el código, la genera y dice con palabras sencillas lo que hizo. Es el camino más corto desde cero hasta una etiqueta terminada. Usa el SDK dentro de su propio programa, sin servidor y sin conexión de red.

## Qué necesitará

- El SDK de .NET 10.
- Windows x64, Linux x64 o Linux arm64.
- Los paquetes del SDK de BarcoderX, cuando estén publicados. Todavía no se puede instalar nada.
- Ninguna clave de licencia. Sin ella, la etiqueta lleva la marca de evaluación.
