# Texto y fuentes

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

Texto en una etiqueta en inglés y en español: alineación, varias líneas y texto que se reduce para caber en su cuadro. Usa la familia de fuentes incorporada en BarcoderX y después una fuente que usted mismo aporta. BarcoderX nunca usa las fuentes instaladas en el equipo, de modo que la etiqueta se ve igual en cualquier máquina.

## Qué necesitará

- El SDK de .NET 10.
- Windows x64, Linux x64 o Linux arm64.
- Los paquetes del SDK de BarcoderX, cuando estén publicados. Todavía no se puede instalar nada.
- Para la segunda parte, un archivo de fuente TrueType (o un archivo OpenType con contornos TrueType) para el que usted tenga licencia, de hasta 10 MB. Este repositorio no incluye ninguno. Usted confirma que tiene su licencia cuando la agrega.
- Ninguna clave de licencia. Sin ella, el resultado lleva la marca de evaluación.
