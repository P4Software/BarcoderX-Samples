# Text and fonts

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

Text on a label in English and Spanish: alignment, several lines, and text that shrinks to fit its box. It uses the font family built into BarcoderX, and then a font that you supply yourself. BarcoderX never uses the fonts installed on the computer, so the label looks the same on every machine.

## What you will need

- The .NET 10 SDK.
- Windows x64, Linux x64 or Linux arm64.
- The BarcoderX SDK packages, once they are released. Nothing can be installed yet.
- For the second part, a TrueType font file (or an OpenType file with TrueType outlines) that you hold a license for, up to 10 MB. This repository does not include one. You confirm that you hold its license when you add it.
- No license key. Without one, the output carries the evaluation mark.
