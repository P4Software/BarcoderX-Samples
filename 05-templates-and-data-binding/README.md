# Templates and data binding

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

A label template saved as a JSON file, connected to a data file with several records, so that one label is made for each record. A field in the template takes its value from the data, and an expression turns the raw value into the text or barcode data that you want to print. The same template is loaded again and gives the same result.

## What you will need

- The .NET 10 SDK.
- Windows x64, Linux x64 or Linux arm64.
- The BarcoderX SDK packages, once they are released. Nothing can be installed yet.
- A small data file in CSV or JSON form. The sample will include one.
- No license key. Without one, the output carries the evaluation mark.
