# Plantillas y vinculación de datos

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

Una plantilla de etiqueta guardada como archivo JSON, conectada a un archivo de datos con varios registros, de modo que se crea una etiqueta por cada registro. Un campo de la plantilla toma su valor de los datos, y una expresión convierte el valor original en el texto o en los datos del código de barras que usted quiere imprimir. La misma plantilla se carga de nuevo y da el mismo resultado.

## Qué necesitará

- El SDK de .NET 10.
- Windows x64, Linux x64 o Linux arm64.
- Los paquetes del SDK de BarcoderX, cuando estén publicados. Todavía no se puede instalar nada.
- Un archivo de datos pequeño en formato CSV o JSON. El ejemplo incluirá uno.
- Ninguna clave de licencia. Sin ella, el resultado lleva la marca de evaluación.
