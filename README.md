# BarcoderX Samples

Sample code for **BarcoderX**, the P4 Software .NET thermal-label and barcode SDK
(design labels in code, render barcodes, print to thermal printers).

Each folder is a small, runnable .NET 10 project that shows one thing. Samples are added as
the SDK ships its features; this repository is empty of code until the first SDK preview.

| Folder | What it shows | Status |
|---|---|---|
| _none yet_ | | |

## How to use

1. Install the .NET 10 SDK.
2. Open the sample folder you want and run `dotnet run`.
3. Each sample has its own `README.md` with what it prints and what to expect.

Product site: https://barcoderx.com · Publisher: P4 Software.
