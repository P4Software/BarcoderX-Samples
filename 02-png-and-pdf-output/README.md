# PNG and PDF output

[Español](README.es.md)

> **Status:** Planned. This folder holds no program yet. It will hold one when the feature is finished. BarcoderX is not released, so nothing here can run today.

## What this sample will show

One template and one set of data, saved as a PNG picture and as a PDF file. The PNG is made at the resolution you ask for, and the PDF is a vector file whose text and barcodes stay sharp at any size. Because both come from the same layout, the two files show the same label.

## What you will need

- The .NET 10 SDK.
- Windows x64, Linux x64 or Linux arm64.
- The BarcoderX SDK packages, once they are released. Nothing can be installed yet.
- A program that opens PNG and PDF files, to look at the result.
- No license key. Without one, both files carry the evaluation mark.
