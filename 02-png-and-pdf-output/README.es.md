# Salida en PNG y PDF

[English](README.md)

> **Estado:** Planificado. Esta carpeta todavía no contiene ningún programa. Lo contendrá cuando la función esté terminada. BarcoderX aún no está publicado, así que hoy nada de lo que hay aquí se puede ejecutar.

## Qué mostrará este ejemplo

Una plantilla y un conjunto de datos, guardados como imagen PNG y como archivo PDF. El PNG se genera con la resolución que usted pida, y el PDF es un archivo vectorial cuyo texto y cuyos códigos de barras se mantienen nítidos en cualquier tamaño. Como ambos salen del mismo diseño, los dos archivos muestran la misma etiqueta.

## Qué necesitará

- El SDK de .NET 10.
- Windows x64, Linux x64 o Linux arm64.
- Los paquetes del SDK de BarcoderX, cuando estén publicados. Todavía no se puede instalar nada.
- Un programa que abra archivos PNG y PDF, para ver el resultado.
- Ninguna clave de licencia. Sin ella, ambos archivos llevan la marca de evaluación.
